Help / Concepts

Reticulum is a networking system designed to work across local networks, radio, and reachable TCP links.

TCP Server vs TCP Client

A TCP Server accepts connections on this machine. A TCP Client connects outward to a remote Reticulum TCP server. Client target host/port must match the server’s reachable address and Listen Port.

Local IP vs Public IP

listen_ip is a local address assigned to this machine—not normally its public Internet address. A remote client uses a reachable address that routes to the server.

Interfaces

An interface is one way this node communicates. AutoInterface discovers nearby nodes on a LAN.

Transport Mode

Routes Reticulum traffic for other nodes. Leave it Off unless this machine is intentionally a transport node.

IFAC

Shared access protection for an interface, similar to a shared Wi-Fi password. IFAC size normally stays at its interface default.

Connecting to another Reticulum server

Create a TCPClientInterface and enter the remote hostname or IP, remote TCP port, IFAC network name and passphrase when used, and an appropriate mode. Outbound TCP Client connections normally do not need router port forwarding.

Name: MTGY Backbone
Type: TCPClientInterface
Target Host: 100.x.x.x
Target Port: 4243
IFAC Network Name: MTGY-Backbone
IFAC Passphrase: <shared value>

Using Tailscale

Tailscale is a good fit for private, trusted Reticulum TCP links. When both nodes are on the same Tailscale network, a TCP Client can use the other node’s Tailscale IP or MagicDNS hostname—no public router port forward is required. A server can bind to its Tailscale IP when it should be reachable only through Tailscale.

Server: TCPServerInterface, listen_port = 4243
Client: TCPClientInterface, target_host = mtgy-server, target_port = 4243

The Reticulum Admin GUI can also be reached privately over Tailscale, avoiding public Internet exposure of the admin portal. This project does not install or configure Tailscale for you.

Public Internet Access

Creating a TCPServerInterface does not automatically open your router or firewall. Direct Internet access requires a reachable public address plus any needed router forwarding, firewall rules, public-server configuration, or another supported networking method. Prefer Tailscale for trusted/private links.

Using Multiple TCP Ports

One local IP can host multiple Reticulum TCP services on different ports:

Public User TCP      0.0.0.0:4242
Trusted Backbone     0.0.0.0:4243
Test/Private         0.0.0.0:4244

Each may use a different IFAC network name, passphrase, and mode. The same IP and same port cannot normally be used by two listeners at once.
