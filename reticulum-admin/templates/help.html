Help / Concepts

Reticulum is a networking system designed to work across many kinds of links, including local networks, radio, and the Internet.

Interfaces

An interface is one way this node communicates. A TCP Server accepts connections; a TCP Client connects outward; AutoInterface discovers nearby nodes on a LAN.

Transport Mode

Routes Reticulum traffic for other nodes. Recommendation: leave it Off unless this machine is intentionally a transport node.

IFAC

Shared access protection for an interface, similar to a shared Wi-Fi password. IFAC size normally stays at its interface default.

Announces, Paths, Queues

An announce advertises reachability. A path is a learned route. A queue holds work awaiting transmission.

Blackholes and Incident Recovery

Blackholing affects this node's own Reticulum segments; it is not a global ban. Incident Recovery clears local dynamic state safely.

Snapshots

Snapshots restore settings, not dynamic paths, announces, or queues.
