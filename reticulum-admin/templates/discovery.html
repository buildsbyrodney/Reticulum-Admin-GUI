Discovery

Reticulum can discover connectable interfaces announced by other nodes. This can reduce the need to manually configure every TCP connection.

Discovery is different from ordinary Reticulum destination announces. It is specifically about learning where connectable Reticulum interfaces are available.

Local Interface Discovery

When enabled, this node listens for Reticulum interface advertisements and can learn about available connections. It does not connect automatically by itself.

Auto-Connect

0 disables auto-connect. A positive limit permits that many discovered interfaces to be connected automatically.

Trusted Discovery Sources

Restricting sources is recommended before enabling auto-connect. These are identity hashes supplied by trusted operators.

For a TCP Server, Discovery Name and Reachable Address are configured in that interface’s Advanced Discovery controls. A TCP Client or AutoInterface can be marked bootstrap-only, but is not offered as an advertised server endpoint.

Discovery Security

Publish IFAC is available only in an interface’s advanced settings. It is off by default because publishing IFAC information distributes that interface’s access credentials through discovery. Enable it only for a deliberately trusted discovery arrangement.

Discovery encryption needs a Reticulum network identity already configured by an experienced operator. This GUI will not create or expose private identity material.

Bootstrap Interfaces

A bootstrap-only interface is used temporarily to help this node find better connectivity. Once a suitable auto-connected interface becomes available, Reticulum can detach the bootstrap interface.

The Bootstrap Node preset is a starting point, not an automatic routing decision.

Recommended setups

  • Trusted Site-to-Site Discovery: enable discovery, use IFAC, and restrict sources before considering auto-connect.
  • Private Tailscale Discovery: Tailscale supplies IP reachability; Reticulum discovery can then locate compatible interfaces. Tailscale is not configured by this GUI.
  • Bootstrap Node: use a temporary known TCP link while discovery finds better connectivity.
