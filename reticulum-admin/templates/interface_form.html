TCP Server settings

The local IP address this Reticulum TCP server listens on. 0.0.0.0 listens on all local IPv4 interfaces; 192.168.1.85 listens only on that local interface. Do not normally enter your public Internet IP here—it must be an address assigned to this machine. For a private Tailscale-only service, bind to this machine’s Tailscale address where appropriate.

The TCP port other Reticulum nodes connect to, such as 4242. There is no mandatory Reticulum TCP port. One IP can use multiple different ports, but two listeners cannot normally use the same IP and port. Think of an IP as a building and a port as a room number.

A TCP Server binds to a local address on this machine. An outside client uses a reachable address that routes to this machine. Creating a TCP Server does not open a router or firewall.

TCP Client settings

The hostname or IP address of the remote Reticulum TCP server: for example 24.181.101.130, mtgy-server, or a Tailscale/MagicDNS hostname.

The remote server’s listening port, such as 4243. It must match that server’s Listen Port.

IFAC Access Protection

IFAC is shared access protection for an interface. It is similar to a shared Wi-Fi password for that Reticulum network segment, not a per-user login.
