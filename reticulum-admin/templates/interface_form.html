IFAC Access Protection

IFAC is shared access protection for an interface. It is similar to a shared Wi-Fi password for that Reticulum network segment, not a per-user login.

Leave this at the interface default unless you have a specific reason to change it. A common default is 8 bytes (64 bits).

Config keys: network_name / passphrase / ifac_size
